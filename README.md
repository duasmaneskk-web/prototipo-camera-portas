# Portas Secretas 
 
**Aluno:** Geovanna da Costa Gonçalves 
**Turma:** 2026.09.67 
**Feito com:** Unity 6 e C# 
 
## Sobre o projeto 
Você tem que escolher a porta certa pra entrar  
 
## O que o projeto faz 
- o jogador movimenta a menina com as setas/WASD
- ao escolher a porta errada, fala pra você ir de novo, quando escolher a porta certa você ganha. 
 
## O que o projeto contém 
- **Scripts:** GerenciadorDePortas, interação, jogador, porta. 
- **Objetos principais:** Porta (1), Porta (2), Porta (3), Beta_Joints, Beta_Surface, Jogador, Chão. 
- **Recursos usados:** MeshCollider, RigyBody, TextMeshPRO, BoxCollider, CharacterController.
 
## Controles 
- W – vai pra frente, S - vai pra trás, A - vai pra esquerda, S - vai pra direita
